# COV v0.3.0-pre.7 — Gaussian FCHK support

Adds direct Gaussian FCHK/FCH input and CHK conversion through an installed `formchk`. Includes point-group and orbital-symmetry analysis, Mayer indices and multicentre orbital views. Molden input and the existing 3D display controls remain available.

The Windows executable is available in the [v0.3 preview archive](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.3.0-pre-archive). The current stable download is [v0.4.0](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.4.0).
