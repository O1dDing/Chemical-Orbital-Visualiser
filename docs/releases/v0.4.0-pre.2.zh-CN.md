# COV v0.4.0-pre.2 — 轨道联系与 NBO 更新

[English](v0.4.0-pre.2.md) · **简体中文** · [日本語](v0.4.0-pre.2.ja.md) · [Français](v0.4.0-pre.2.fr.md)

此预览版改进了轨道名称、图示布局和 NBO 文件读取。

- 轨道对称性名称更清楚，相关操作也更简洁。
- 调整了 AO–MO 图和局域轨道能量的显示。对于限制性开壳层计算，简要分析中会合并显示空间上对应的 α、β 局域轨道。
- NBO 矩阵文件读取更快。计算文件准备和 NBO 使用说明补齐了英、中、日、法四种语言。

计算指南：[准备 NBO 文件](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.2/docs/NBO_ONE_JOB.zh-CN.md) · [使用 NBO 结果](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.2/docs/AOMO_NBO.zh-CN.md)

[下载 Windows ZIP 压缩包](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre-archive/Chemical-Orbital-Visualiser-v0.4.0-pre.2-Windows-sm120.zip)。解压后运行 `program/cov.exe`，也可以使用压缩包内的 `Open-*.cmd` 启动脚本打开示例。

此 Windows 版本支持 NVIDIA RTX 50 系列显卡，需要兼容的驱动程序和 OpenGL 2.1。输入上限为 100 个原子。打开已有的 FCHK/FCH 和 NBO 文件无需安装 Gaussian 或 NBO。打开 CHK 文件需要另行安装 `formchk`。
