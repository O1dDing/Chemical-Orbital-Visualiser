# COV v0.4.0 — 轨道能量、组成与 NBO 分析

[English](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/docs/releases/v0.4.0.md) · **简体中文** · [日本語](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/docs/releases/v0.4.0.ja.md) · [Français](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/docs/releases/v0.4.0.fr.md)

查看轨道能量与电子占据、导出能级图，并追踪原子轨道、局域轨道与分子轨道之间的联系。COV v0.4.0 在 Windows、macOS 和 Linux 上提供 NBO 分析。

- 打开 Gaussian FCHK/FCH 或兼容的 Molden 文件，浏览轨道能量与占据，查看轨道的三维形状。
- 配合相应的 NBO 文件，查看 AO–MO 组成、NAO、NBO、NHO、NLMO 和 SALC 视图，以及 NPA 电荷、自旋布居、Wiberg 指数和供体–受体相互作用。
- 查看对称性与轨道组名称、受限开壳层对应轨道的共享能量，以及适用配合物的金属/配体组成。简要视图可同时筛除内层、配体背景及相应的 AO/SALC 贡献。
- 查看简并轨道组和等价键，使用浮动轨道详情及标签开关。视图和导出图片中的科学标签保留上标、下标、原子编号和片段编号。
- 导出 PNG/SVG 图片及 CSV/JSON 数据。界面和使用指南提供英文、简体中文、日文和法文版本。

## 下载

[Windows x64 ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0/Chemical-Orbital-Visualiser-v0.4.0-Windows-x64.zip) · [macOS 通用 ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0/Chemical-Orbital-Visualiser-v0.4.0-macOS-universal.zip) · [Linux x86_64 tar.gz](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0/Chemical-Orbital-Visualiser-v0.4.0-Linux-x86_64.tar.gz)

所有程序包均需要 OpenGL 2.1 或更新版本，并支持 CPU 计算。Windows x64 包含 CUDA 12.8；使用 CUDA 需要兼容的 NVIDIA 驱动。macOS 12 及更新版本支持 Apple Silicon 和 Intel，提供 Metal 与 CPU 计算。Linux x86_64 使用 CPU 计算，程序包以 Ubuntu 22.04 为基线。

解压后，Windows 运行 `cov.exe`，macOS 打开 `Chemical Orbital Visualiser.app`，Linux 运行 `./cov`。每个输入最多包含 100 个原子。查看已有 FCHK/FCH、Molden 和 NBO 文件无需安装 Gaussian 或 NBO；转换 CHK 需要单独安装 `formchk`。

[分子样本库](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/examples/molecules/README.zh-CN.md)提供 47 个计算样本，包括水、甲烷、苯和交错构象的二茂铁。
