# COV v0.4.0-pre.2 — 軌道のつながりと NBO の更新

[English](v0.4.0-pre.2.md) · [简体中文](v0.4.0-pre.2.zh-CN.md) · **日本語** · [Français](v0.4.0-pre.2.fr.md)

このプレビューでは、軌道名、図のレイアウト、NBO ファイルの読み込みを改善しました。

- 軌道の対称性名が分かりやすくなり、操作も簡潔になりました。
- AO–MO 図と局在軌道エネルギーの表示を調整しました。制限開殻計算では、空間的に対応する α・β 局在軌道を概要表示でまとめて表示します。
- NBO 行列ファイルの読み込みが速くなりました。計算ファイルの準備と NBO の使い方を英語・中国語・日本語・フランス語で用意しました。

計算ガイド：[NBO ファイルの準備](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.2/docs/NBO_ONE_JOB.ja.md) · [NBO 結果の使い方](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.2/docs/AOMO_NBO.ja.md)

[Windows ZIP をダウンロード](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre-archive/Chemical-Orbital-Visualiser-v0.4.0-pre.2-Windows-sm120.zip)。展開後に `program/cov.exe` を実行するか、同梱の `Open-*.cmd` ランチャーでサンプルを開いてください。

この Windows 版は NVIDIA RTX 50 シリーズに対応し、互換性のあるドライバーと OpenGL 2.1 が必要です。入力は最大 100 原子です。既存の FCHK/FCH・NBO ファイルを開く際、Gaussian や NBO のインストールは不要です。CHK ファイルを開く場合は、別途 `formchk` が必要です。
