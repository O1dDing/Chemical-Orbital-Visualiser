# COV v0.4.0 — 軌道エネルギー、組成と NBO 解析

[English](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/docs/releases/v0.4.0.md) · [简体中文](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/docs/releases/v0.4.0.zh-CN.md) · **日本語** · [Français](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/docs/releases/v0.4.0.fr.md)

軌道のエネルギーと電子占有数を確認し、エネルギー準位図を書き出し、原子軌道・局在軌道・分子軌道のつながりをたどれます。COV v0.4.0 は Windows、macOS、Linux で NBO 解析に対応します。

- Gaussian の FCHK/FCH または互換性のある Molden ファイルを開き、軌道エネルギーと占有数、軌道の 3D 形状を確認できます。
- 対応する NBO ファイルがあれば、AO–MO 組成、NAO、NBO、NHO、NLMO、SALC の表示、NPA 電荷、スピン分布、Wiberg 指数、供与体–受容体相互作用を調べられます。
- 対称性と軌道群の名前、制限開殻計算の対応軌道に共通するエネルギー、対象となる錯体の金属・配位子組成を表示します。簡略表示では、内殻・配位子の背景と対応する AO/SALC 寄与をまとめて絞り込めます。
- 縮退軌道群や等価な結合を確認し、軌道詳細のフローティング表示とラベルの切り替えを利用できます。画面と書き出した図の科学表記では、上付き・下付き文字、原子の番号、フラグメントの番号を保ちます。
- PNG/SVG の図と CSV/JSON のデータを書き出せます。画面と利用ガイドは英語、簡体字中国語、日本語、フランス語に対応します。

## ダウンロード

[Windows x64 ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0/Chemical-Orbital-Visualiser-v0.4.0-Windows-x64.zip) · [macOS ユニバーサル ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0/Chemical-Orbital-Visualiser-v0.4.0-macOS-universal.zip) · [Linux x86_64 tar.gz](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0/Chemical-Orbital-Visualiser-v0.4.0-Linux-x86_64.tar.gz)

すべてのパッケージで OpenGL 2.1 以降が必要です。各環境で CPU 計算を利用できます。Windows x64 版は CUDA 12.8 を含み、CUDA の利用には互換性のある NVIDIA ドライバーが必要です。macOS 12 以降は Apple Silicon と Intel に対応し、Metal と CPU で計算します。Linux x86_64 版は CPU で計算し、Ubuntu 22.04 をパッケージの基準としています。

展開後、Windows は `cov.exe`、macOS は `Chemical Orbital Visualiser.app`、Linux は `./cov` を起動します。入力は最大 100 原子です。既存の FCHK/FCH、Molden、NBO ファイルの表示には Gaussian や NBO のインストールは不要です。CHK の変換には別途インストールした `formchk` が必要です。

[分子サンプル集](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/examples/molecules/README.ja.md)には、水、メタン、ベンゼン、ねじれ形フェロセンなど、47 件の計算サンプルがあります。
