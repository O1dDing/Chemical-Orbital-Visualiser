# COV v0.4.0-pre.4 — orbital analysis on Windows, macOS and Linux

**English** · [简体中文](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.zh-CN.md) · [日本語](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.ja.md) · [Français](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.fr.md)

Explore orbital energies, occupations and AO–MO connections, with NBO charge and bonding information when the matching files contain it.

- Read symmetry and group names for the current view, with shared energies for matching restricted-open-shell orbitals.
- Inspect metal/ligand composition for applicable complexes, and use a brief view that filters core and ligand background together with matching AO/SALC contributions.
- Read consistent bonding displays for degenerate orbital groups and equivalent bonds, with floating orbital details and label toggles.
- Open the same version on Windows, macOS or Linux, and export energy-level figures as PNG or SVG.

All packages require OpenGL 2.1 or newer. Windows x64 includes CUDA 12.8 with CPU fallback; CUDA needs a compatible NVIDIA driver. macOS 12 or newer supports Apple Silicon and Intel, with Metal and CPU computation. Linux x86_64 uses CPU computation and has Ubuntu 22.04 as its package baseline. An NVIDIA GPU is not required to open COV.

After extraction, run `cov.exe` on Windows, open `Chemical Orbital Visualiser.app` on macOS, or run `./cov` on Linux. The input limit is 100 atoms. Existing FCHK/FCH, Molden and NBO files can be opened without installing Gaussian or NBO; CHK conversion requires a separately installed `formchk`.

Calculation guides: [Prepare NBO files](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/NBO_ONE_JOB.md) · [Use NBO results](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/AOMO_NBO.md)

This is a prerelease; features and file compatibility may change before the stable v0.4 release.
