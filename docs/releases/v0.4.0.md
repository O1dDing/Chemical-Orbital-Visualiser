# COV v0.4.0 — orbital energies, composition and NBO analysis

**English** · [简体中文](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/docs/releases/v0.4.0.zh-CN.md) · [日本語](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/docs/releases/v0.4.0.ja.md) · [Français](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/docs/releases/v0.4.0.fr.md)

Explore orbital energies and occupations, export energy-level diagrams, and follow the connections between atomic, localised and molecular orbitals. COV v0.4.0 brings NBO analysis to Windows, macOS and Linux.

- Open Gaussian FCHK/FCH or compatible Molden files, browse orbital energies and occupations, and inspect orbital shapes in 3D.
- With matching NBO files, inspect AO–MO composition, NAO, NBO, NHO, NLMO and SALC views, NPA charges, spin populations, Wiberg indices and donor–acceptor interactions.
- Read symmetry and group names, shared energies for matching restricted-open-shell orbitals, and metal/ligand composition for applicable complexes. A brief view filters core and ligand background together with the corresponding AO/SALC contributions.
- Inspect degenerate orbital groups and equivalent bonds, with floating orbital details and label controls. Scientific labels retain their subscripts, superscripts, atom indices and fragment indices in the views and exported figures.
- Export PNG/SVG figures and CSV/JSON data. The interface and usage guides are available in English, Simplified Chinese, Japanese and French.

[Windows x64 ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0/Chemical-Orbital-Visualiser-v0.4.0-Windows-x64.zip) · [macOS universal ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0/Chemical-Orbital-Visualiser-v0.4.0-macOS-universal.zip) · [Linux x86_64 tar.gz](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0/Chemical-Orbital-Visualiser-v0.4.0-Linux-x86_64.tar.gz)

All packages require OpenGL 2.1 or newer and include CPU computation. Windows x64 includes CUDA 12.8; CUDA use needs a compatible NVIDIA driver. macOS 12 or newer supports Apple Silicon and Intel, with Metal and CPU computation. Linux x86_64 uses CPU computation and has Ubuntu 22.04 as its package baseline.

After extraction, run `cov.exe` on Windows, open `Chemical Orbital Visualiser.app` on macOS, or run `./cov` on Linux. The input limit is 100 atoms. Existing FCHK/FCH, Molden and NBO files can be opened without installing Gaussian or NBO; CHK conversion requires a separately installed `formchk`.

The [molecule sample library](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0/examples/molecules/README.md) provides 47 calculation variants, including water, methane, benzene and staggered ferrocene.
