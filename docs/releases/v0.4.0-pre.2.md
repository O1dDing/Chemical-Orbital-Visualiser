# COV v0.4.0-pre.2 — orbital connections and NBO updates

**English** · [简体中文](v0.4.0-pre.2.zh-CN.md) · [日本語](v0.4.0-pre.2.ja.md) · [Français](v0.4.0-pre.2.fr.md)

This preview refines orbital names, layouts and NBO loading.

- Orbital symmetry names are clearer, and the orbital controls are simpler to use.
- Updated AO–MO diagrams and local-orbital energies. In restricted-open-shell calculations, matching α and β local orbitals are shown together in the overview.
- NBO matrix files load faster. The calculation-file and NBO guides are available in English, Chinese, Japanese and French.

Calculation guides: [Prepare NBO files](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.2/docs/NBO_ONE_JOB.md) · [Use NBO results](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.2/docs/AOMO_NBO.md)

[Download the Windows ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre-archive/Chemical-Orbital-Visualiser-v0.4.0-pre.2-Windows-sm120.zip). After extraction, run `program/cov.exe`, or use an included `Open-*.cmd` launcher to open an example.

This Windows build supports NVIDIA RTX 50-series GPUs and requires a compatible driver and OpenGL 2.1. The input limit is 100 atoms. Existing FCHK/FCH and NBO files can be opened without installing Gaussian or NBO. Opening a CHK file requires a separately installed `formchk`.
