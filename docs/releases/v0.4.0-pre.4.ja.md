# COV v0.4.0-pre.4 — Windows・macOS・Linux での軌道解析

[English](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.md) · [简体中文](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.zh-CN.md) · **日本語** · [Français](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.fr.md)

軌道のエネルギーと占有数、AO–MO のつながりを調べられます。対応するファイルにデータがあれば、NBO の電荷と結合情報も表示できます。

- 現在の表示に対応する対称性と軌道群の名前、制限開殻計算の対応軌道に共通するエネルギーを確認できます。
- 対象となる錯体の金属・配位子組成を確認できます。簡略表示では、内殻・配位子の背景と対応する AO/SALC 寄与をまとめて絞り込めます。
- 縮退軌道群と等価な結合の結合表示をそろえ、軌道詳細のフローティング表示やラベルの切り替えを利用できます。
- Windows、macOS、Linux で同じ版を使い、エネルギー準位図を PNG または SVG で書き出せます。

## ダウンロード

[Windows x64 ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre.4/Chemical-Orbital-Visualiser-v0.4.0-pre.4-Windows-x64.zip) · [macOS universal ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre.4/Chemical-Orbital-Visualiser-v0.4.0-pre.4-macOS-universal.zip) · [Linux x86_64 tar.gz](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre.4/Chemical-Orbital-Visualiser-v0.4.0-pre.4-Linux-x86_64.tar.gz)

すべてのパッケージに OpenGL 2.1 以降が必要です。Windows x64 版は CUDA 12.8 を含み、CPU にも切り替えられます。CUDA の利用には互換性のある NVIDIA ドライバーが必要です。macOS 12 以降は Apple Silicon と Intel に対応し、Metal と CPU で計算します。Linux x86_64 版は CPU で計算し、パッケージの基準は Ubuntu 22.04 です。COV の起動に NVIDIA GPU は必要ありません。

展開後、Windows は `cov.exe`、macOS は `Chemical Orbital Visualiser.app`、Linux は `./cov` を起動します。入力ファイルあたり最大 100 原子です。既存の FCHK/FCH、Molden、NBO ファイルは Gaussian や NBO をインストールせずに開けます。CHK の変換には別途インストールした `formchk` が必要です。

計算ファイルのガイド：[NBO ファイルの準備](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/NBO_ONE_JOB.ja.md) · [NBO の結果を使う](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/AOMO_NBO.ja.md)

これはプレリリース版です。正式版 v0.4 までに機能やファイルの互換性が変更される場合があります。
