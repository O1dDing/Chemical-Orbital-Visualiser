# COV v0.4.0-pre.4 — analyse orbitale sous Windows, macOS et Linux

[English](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.md) · [简体中文](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.zh-CN.md) · [日本語](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.ja.md) · **Français**

Explorez les énergies, les occupations et les liens AO–MO, ainsi que les charges et les liaisons NBO lorsque les fichiers correspondants contiennent ces données.

- Consultez les noms de symétrie et de groupes de la vue actuelle, avec les énergies communes des orbitales correspondantes des calculs à couche ouverte restreints.
- Examinez la composition métal/ligand des complexes concernés. La vue simplifiée peut filtrer le fond de cœur et de ligand avec les contributions AO/SALC correspondantes.
- Lisez un affichage de liaison cohérent pour les groupes orbitaux dégénérés et les liaisons équivalentes, avec les détails flottants des orbitales et les commandes d’étiquettes.
- Ouvrez la même version sous Windows, macOS ou Linux et exportez les diagrammes de niveaux d’énergie en PNG ou SVG.

## Téléchargements

[Windows x64 ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre.4/Chemical-Orbital-Visualiser-v0.4.0-pre.4-Windows-x64.zip) · [macOS universal ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre.4/Chemical-Orbital-Visualiser-v0.4.0-pre.4-macOS-universal.zip) · [Linux x86_64 tar.gz](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre.4/Chemical-Orbital-Visualiser-v0.4.0-pre.4-Linux-x86_64.tar.gz)

Tous les paquets nécessitent OpenGL 2.1 ou ultérieur. Windows x64 inclut CUDA 12.8 avec repli sur le CPU ; CUDA nécessite un pilote NVIDIA compatible. macOS 12 ou ultérieur prend en charge Apple Silicon et Intel, avec le calcul sur Metal et CPU. Linux x86_64 utilise le CPU, avec Ubuntu 22.04 comme base du paquet. Un GPU NVIDIA n’est pas nécessaire pour ouvrir COV.

Après extraction, lancez `cov.exe` sous Windows, ouvrez `Chemical Orbital Visualiser.app` sous macOS, ou lancez `./cov` sous Linux. La limite est de 100 atomes par fichier d’entrée. Les fichiers FCHK/FCH, Molden et NBO existants peuvent être ouverts sans installer Gaussian ou NBO ; la conversion des fichiers CHK nécessite un utilitaire `formchk` installé séparément.

Guides des fichiers de calcul : [Préparer les fichiers NBO](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/NBO_ONE_JOB.fr.md) · [Utiliser les résultats NBO](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/AOMO_NBO.fr.md)

Il s’agit d’une préversion ; les fonctionnalités et la compatibilité des fichiers peuvent évoluer avant la version stable v0.4.
