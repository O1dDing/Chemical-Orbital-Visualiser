# COV v0.3.0 — Orbital energies and diagrams

View orbital energies and occupations from Gaussian FCHK/FCH or Molden files, compare energy levels, export figures and inspect orbitals in 3D.

[Download the Windows ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.3.0/CUDA-Orbital-Visualisation-v0.3.0-Windows-sm120.zip). Extract it and run `cov.exe`. A small example is included at `examples/h2.molden`.

This Windows build supports NVIDIA RTX 50-series GPUs and requires a compatible driver and OpenGL 2.1. The input limit is 100 atoms. Opening a Gaussian CHK file requires a separately installed `formchk`.

NBO analysis is available in [v0.4.0](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.4.0).
