# COV v0.4.0-pre.4 — Windows、macOS 与 Linux 上的轨道分析

[English](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.md) · **简体中文** · [日本語](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.ja.md) · [Français](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/releases/v0.4.0-pre.4.fr.md)

查看轨道能量、电子占据及 AO–MO 联系；配套文件包含相关数据时，还可查看 NBO 电荷与成键信息。

- 查看当前视图的对称性与轨道组名称，以及受限开壳层对应轨道的共享能量。
- 查看适用配合物的金属/配体组成；简要视图可同时筛除内层和配体背景及匹配的 AO/SALC 贡献。
- 简并轨道组和等价键采用一致的成键显示，并提供浮动轨道详情和标签开关。
- 在 Windows、macOS 或 Linux 上使用同一版本，将能级图导出为 PNG 或 SVG。

## 下载

[Windows x64 ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre.4/Chemical-Orbital-Visualiser-v0.4.0-pre.4-Windows-x64.zip) · [macOS universal ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre.4/Chemical-Orbital-Visualiser-v0.4.0-pre.4-macOS-universal.zip) · [Linux x86_64 tar.gz](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre.4/Chemical-Orbital-Visualiser-v0.4.0-pre.4-Linux-x86_64.tar.gz)

所有程序包需要 OpenGL 2.1 或更新版本。Windows x64 包含 CUDA 12.8，并可回退至 CPU；使用 CUDA 需要兼容的 NVIDIA 驱动。macOS 12 及更新版本支持 Apple Silicon 和 Intel，提供 Metal 与 CPU 计算。Linux x86_64 使用 CPU 计算，程序包以 Ubuntu 22.04 为基线。打开 COV 不要求 NVIDIA 显卡。

解压后，Windows 运行 `cov.exe`，macOS 打开 `Chemical Orbital Visualiser.app`，Linux 运行 `./cov`。每个输入最多包含 100 个原子。已有的 FCHK/FCH、Molden 和 NBO 文件无需安装 Gaussian 或 NBO 即可打开；CHK 转换需要另行安装 `formchk`。

计算文件指南：[准备 NBO 文件](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/NBO_ONE_JOB.zh-CN.md) · [使用 NBO 结果](https://github.com/O1dDing/Chemical-Orbital-Visualiser/blob/v0.4.0-pre.4/docs/AOMO_NBO.zh-CN.md)

这是预发布版本；正式发布 v0.4 前，功能与文件兼容性可能调整。
