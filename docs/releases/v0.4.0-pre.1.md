# COV v0.4.0-pre.1 — NBO analysis and orbital connections

This preview adds NBO analysis to COV's orbital lists, energy diagrams and 3D views. Open a calculation folder to explore orbital composition, charges, bond indices and donor–acceptor interactions.

- View AO, NAO, NBO, NHO and NLMO contributions where the calculation includes the required files.
- Select an atom, bond, orbital or connection to inspect the related data.
- Export energy diagrams, orbital-connection figures and data tables.

[Download the Windows ZIP](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/v0.4.0-pre-archive/CUDA-Orbital-Visualisation-v0.4.0-pre.1-Windows-sm120.zip). After extraction, run `program/cov.exe`, or open one of the included examples with an `Open-*.cmd` launcher.

This Windows build supports NVIDIA RTX 50-series GPUs and requires a compatible driver and OpenGL 2.1. The input limit is 100 atoms. Gaussian, NBO and `formchk` are installed separately.

Missing NBO files affect the corresponding NBO views. The molecular orbitals remain available from the wavefunction file.
