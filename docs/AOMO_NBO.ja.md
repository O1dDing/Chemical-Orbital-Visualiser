# AO–MO と NBO のつながりを調べる

[English](AOMO_NBO.md) · [简体中文](AOMO_NBO.zh-CN.md) · **日本語** · [Français](AOMO_NBO.fr.md)

Chemical Orbital Visualiser（COV）では、軌道のエネルギー、占有数、組成を一つの画面で確認できます。v0.4.0 プレビュー版では、既存の Gaussian FCHK と対応する NBO の結果を開き、MO、原子、結合から関連する軌道や寄与をたどれます。形状を確認したいときは、選択した軌道を 3D で表示できます。

## 必要なファイル

COV は既存の結果を読み込みます。Gaussian や NBO の計算は実行しません。ファイルをまとめてドラッグする、フォルダーをドラッグする、またはパスを入力する方法で開けます。フォルダーに複数の計算がある場合は、開く計算を選びます。ファイルが別々の場所にある場合は、詳細なパス設定を使えます。

| 確認したい内容 | 用意するファイル |
| --- | --- |
| MO のエネルギー、占有数、準位図、Gaussian AO–MO 係数の対応、MO の 3D 表示 | Gaussian FCHK/FCH。Molden では基本的な MO 表示に対応します。 |
| レポートに記載された NPA 電荷、Wiberg 指数、E(2) 値 | FCHK と、該当する項目を含む NBO レポート。 |
| NAO の形状、NPA 電荷と Wiberg 指数による色分け | 基本ファイルと AONAO、および対応する密度データ。 |
| NAO で表した MO の組成 | 基本ファイル、AONAO、NAOMO。NAONBO は別の変換を提供します。 |
| NBO の形状と正準 MO–NBO のつながり | 基本ファイルと AONBO。MO との対応には、FCHK 内の対応する正準 MO 係数を使います。 |
| NHO の形状と成分 | 基本ファイル、AONAO、AONHO、NAONHO。NHO–NBO の対応には NHONBO と AONBO も使います。 |
| NLMO の形状、主な NBO 成分、テール | 基本ファイル、AONBO、AONLMO、NBONLMO、および対応するレポート項目。MO との対応には、FCHK 内の対応する正準 MO 係数を使います。 |
| PNAO の形状 | 基本ファイル、AONAO、AOPNAO。 |
| SALC の形状 | 基本ファイルと AONAO、および対称性に基づく組み合わせを構成できる分子構造と選択した軌道空間。 |
| 演算子から計算した NAO と SALC のエネルギー | 対応する軌道と Fock データ。その計算に必要なスピン成分も含みます。 |
| E(2) の供与体–受容体軌道 | 基本ファイル、AONBO、および供与体と受容体を特定するレポート項目。 |

基本ファイルとは、互いに対応する FCHK、NBO レポート、`.47` アーカイブです。FCHK と NBO データは同じ波動関数を表す必要があります。レポートと軌道行列は同じ NBO 解析で出力されたものを使います。GenNBO で再解析した場合は、その再解析のレポートと行列を使います。アーカイブには分子構造、基底、重なり、密度、正準 MO 係数が含まれます。スピンによる色分けには、対応するスピン別の密度とレポートデータも必要です。

NBOMO と NLMOMO があれば、追加の変換を利用できます。COV は局在軌道の係数、重なり、正準 MO 係数から MO との対応を計算することもできるため、この二つのファイルが常に必要なわけではありません。FCHK に一方のスピンの正準 MO 係数がない場合、そのスピンの MO との対応は表示できません。

レポートに記載された E(2) 値を読むだけの場合や、対応する供与体と受容体の軌道を表示する場合には、Fock データは必要ありません。Fock データがあれば、レポートの相互作用行列要素とエネルギー差を行列から得られる値と比較できます。レポートに記載された NAO/NBO のエネルギーは、アーカイブ内に Fock 行列がなくても利用できる場合があります。SALC の形状と、その計算されたエネルギーでは、必要なデータが異なります。

行列ファイルの番号は NBO の出力設定で決まります。COV は行列の見出しから内容を識別します。`canonical.fchk` と `analysis.nbo` はテンプレートで使う名前であり、必須のファイル名ではありません。`.covnbopkg` ファイルは開くファイルの一覧です。フォルダーを開く方法や、ファイルを選択する方法も使えます。

計算の順序、出力オプション、不足するファイルについては、[計算ファイルの準備](NBO_ONE_JOB.ja.md)をご覧ください。現在、NBO データとの対応には Gaussian FCHK/FCH を使います。通常の MO 表示には Molden も利用できます。NBO データがない場合も、通常の MO 表示は利用できます。

## 準位図で軌道のつながりをたどる

軌道一覧またはエネルギー準位図で MO を選びます。準位図は価電子準位とその近くの空軌道に焦点を当てています。軌道一覧の **すべて** では、読み込んだすべての軌道を表示できます。MO をクリックすると、利用可能な Gaussian 原子軌道（AO）、自然原子軌道（NAO）、原子グループとのつながりが強調されます。AO、NAO、またはつながりをクリックすると、寄与を確認したり、関連する MO を探したりできます。複数の項を選択し、符号を含めた部分和や重ね合わせを 3D で表示することもできます。グループを折りたたむと、構成要素を削除せずに図を整理できます。

NAO は直交した表現を構成するため、NAO 係数の二乗はその表現での重みを表せます。元の Gaussian AO は一般に非直交であり、その係数の二乗を原子ごとの電子数として扱うことはできません。NAO や SALC のエネルギーが利用できる場合は、MO と同じ数値軸に表示できます。これらの値は分子環境内での演算子の期待値であり、中央に示す値は正準 MO エネルギーです。模式的な側面配置では、軌道のエネルギーを使わずに配置します。軌道のグループを SALC と呼べるのは、利用可能なデータがその対称性の意味を裏付ける場合だけです。

局在軌道の基底には、Gaussian AO 基底より少ない数の軌道しか含まれないことがあります。その場合、準位図では利用可能な寄与とカバーされない部分を表示し、寄与の合計が 100% になるような換算は行いません。

**概要** は簡潔な表示です。**研究用解析** では詳しい情報を表示し、**全軌道** では内殻軌道と Rydberg 軌道も含めます。これらのプリセットは表示する内容を変更します。

## 分子から調べる

3D 表示で原子や結合をクリックすると、関連する値と軌道へのつながりを開けます。レポートと対応する行列があれば、原子を NPA 電荷やスピン分布で色分けできます。結合では Wiberg 指数、結合性軌道と反結合性軌道、配位関係や多中心の関係を確認できます。Wiberg 指数は連続的な値であり、整数の結合次数ではありません。

NHO 表示では、方向性のある軌道ローブとその角運動量成分を確認できます。E(2) 相互作用を選択すると、供与体と受容体の軌道を一緒に表示できます。E(2) 値は摂動論による推定値であり、結合エネルギーや反応エネルギーではありません。必要なデータがあれば、NLMO 表示で軌道全体、主な NBO 成分、残りのテールを分けて表示できます。

小さな寄与は、現在の等値面のしきい値では見えない場合があります。**成分に合わせる** で表示のしきい値を調整するか、**骨格を表示** で分子を見やすくできます。異なる軌道の大きさを比較するときは、同じしきい値を使ってください。

## 書き出し

**画像を書き出す** で PNG と SVG を保存します。数値が必要な場合は、**解析データ（詳細）→ 解析データを書き出す** で JSON/CSV と関連する解析ファイルを別途保存できます。操作しながら調べる 3D 表示は COV 内で利用します。
