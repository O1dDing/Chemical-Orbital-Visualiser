# COV 用の計算ファイルを準備する

[English](NBO_ONE_JOB.md) · [简体中文](NBO_ONE_JOB.zh-CN.md) · **日本語** · [Français](NBO_ONE_JOB.fr.md)

FCHK/FCH または Molden ファイルには、分子軌道のエネルギー、占有数、形状のデータが含まれます。NBO 軌道の形状や組成の解析には、対応する NBO レポート、`.47` アーカイブ、軌道行列も必要です。各表示に必要なファイルは、[NBO の結果を使う](AOMO_NBO.ja.md)に記載しています。

## 計算から COV へ

まず波動関数を計算します。Gaussian はそのジョブ内で NBO を実行できます。`formchk` で正準軌道を保持したチェックポイントを FCHK に書き出します。GenNBO は保存した `.47` アーカイブを読み込み、SCF 計算を繰り返さずに、別の NBO レポートと指定した行列を出力できます。

FCHK と NBO データは、同じ分子構造、基底、電子状態を表すものを使います。GenNBO で再解析するときは異なる解析オプションを使うこともあるため、その再解析のレポートと行列を一緒に使います。必要に応じて、この手順の前に構造最適化や振動数計算を行えます。既存の波動関数を表示するだけなら、それらは必要ありません。

[一括実行テンプレート](../examples/nbo-one-job/cov_one_job.py)は Gaussian/NBO、`formchk`、GenNBO を順に実行し、COV 用に出力をまとめます。COV アプリケーションは、その結果を開きます。

## Windows 用テンプレートを使う

このテンプレートは、COV のソースツリーで Python 3.11 以降、Gaussian 16W A.03、NBO7 i8 を使って実行します。Gaussian と NBO はあらかじめインストールし、`gaunbo6.bat` がその NBO インストール先を参照するように設定しておく必要があります。A.03 は `Pop=NBO6Read` で NBO7 を呼び出します。ほかの Gaussian リビジョンでは、それぞれのインターフェース設定を使います。このテンプレートは A.03 であることを確認します。

テンプレートはソースツリー内の [tests/validation_process.py](../tests/validation_process.py) を使います。

[water.json](../examples/nbo-one-job/water.json) をコピーし、分子、構造、計算手法、基底、電荷、多重度を設定します。サンプルは、固定構造の水分子について PBE1PBE / 6-31G(d) を使う一点計算で、電荷は 0、多重度は 1 です。必要な場合は、`basis_ecp_tail` に明示的な基底/ECP ブロックを指定できます。

ソースツリーのルートから、インストール先のパスと新しい出力フォルダーを指定して実行します。

```powershell
python examples/nbo-one-job/cov_one_job.py `
  --recipe examples/nbo-one-job/water.json `
  --output work/water-job `
  --gaussian-bin 'C:/Gaussian/Gaussian 16 W' `
  --nbo-bin 'C:/NBO/bin'
```

このコマンドは、ファイルを作成したり計算を開始したりせずに、入力をプレビューし、パスを確認します。同じコマンドに `--run` を加えると、実行を開始します。出力フォルダーには、まだ存在しないフォルダーを指定する必要があります。テンプレートは指定された構造を保持し、単一の一点計算を実行します。構造最適化や振動数計算には、それぞれ専用の入力が必要です。

テンプレートで使用できる Gaussian スレッド数は最大 3 です。プロセスツリー全体の上限は 3 コア、20 GiB です。タイムアウトは Gaussian が 900 秒、`formchk` が 300 秒、GenNBO が 600 秒です。`--memory-limit-gib` と `--gaussian-timeout` で記載された上限を調整できます。オプションの一覧は `--help` で確認できます。

## 結果を開く

COV で `work/water-job/cov-package` を開くか、その中の `drop.covnbopkg` を COV にドラッグします。フォルダーには `canonical.fchk`、一つの `analysis.nbo` レポート、`.47` アーカイブ、指定した軌道行列が入っています。

`cov-package` 内のレポート、アーカイブ、行列は、同じ GenNBO 解析で出力されたものです。`canonical.fchk` と `analysis.nbo` はテンプレートで使うファイル名であり、COV で必須の名前ではありません。`.covnbopkg` ファイルは開くファイルの一覧であり、追加の軌道データを提供するものではありません。

テンプレートは元のチェックポイントと Gaussian アーカイブを保存します。実行記録は入力フォルダーの外に保存されます。ジョブが失敗した場合も出力は保持されます。再試行するときは、新しいフォルダーを使います。

## 行列の出力

以下はテンプレートの出力設定です。番号は NBO で変更できます。行列の見出しが内容を識別します。テンプレートは幅広いファイルを出力するように設定されていますが、個々の COV 表示で必要なのは、その一部だけの場合があります。

| 出力オプション | ファイル | 内容 |
| --- | --- | --- |
| `AONBO=W37` | `FILE.37` | AO 基底での NBO 係数 |
| `NBOMO=W49` | `FILE.49` | NBO 基底での MO 係数 |
| `SAO=W50` | `FILE.50` | AO 重なり行列 |
| `NAOMO=W51` | `FILE.51` | NAO 基底での MO 係数 |
| `AONAO=W52` | `FILE.52` | AO 基底での NAO 係数 |
| `NAONBO=W53` | `FILE.53` | NAO 基底での NBO 係数 |
| `AONHO=W54` | `FILE.54` | AO 基底での NHO 係数 |
| `AONLMO=W55` | `FILE.55` | AO 基底での NLMO 係数 |
| `AOPNAO=W56` | `FILE.56` | AO 基底での直交化前の NAO 係数 |
| `NAONHO=W57` | `FILE.57` | NAO 基底での NHO 係数 |
| `NAONLMO=W58` | `FILE.58` | NAO 基底での NLMO 係数 |
| `NHONBO=W59` | `FILE.59` | NHO 基底での NBO 係数 |
| `NBONLMO=W60` | `FILE.60` | NBO 基底での NLMO 係数 |
| `NLMOMO=W61` | `FILE.61` | NLMO 基底での MO 係数 |
| `AOMO=W62` | `FILE.62` | AO 基底での正準 MO 係数 |

`ARCHIVE` は `.47` ファイルを書き出します。`PRINT=3` は NLMO と Wiberg の出力を含めます。テンプレートでは `E2PERT=0.0` も指定しています。NBO キーリスト全体は [cov_one_job.py](../examples/nbo-one-job/cov_one_job.py) にあります。

`.47` ファイルに Fock データが含まれているとは限りません。このテンプレートはエネルギー表示用の入力も準備するため、アーカイブに重なり、密度、正準 MO、Fock のいずれかのセクションがなければ停止します。不足したデータが不要な表示については、COV はより少ないファイルでも利用できます。開殻系の表示には対応するスピンデータが必要です。テンプレートが分子に応じて制限法や非制限法を選択することはありません。

## ファイルの保存と復元

元の入力、計算ログ、チェックポイントは、後で追加のデータを書き出すときに役立ちます。既存の書き出し済みファイルを開くために、そのすべてが必要なわけではありません。正準 FCHK は、正準 MO を保持したチェックポイントから作成します。SaveNBOs や SaveNLMOs は、チェックポイント内の軌道を置き換える場合があります。

| 不足しているもの | 復元方法 |
| --- | --- |
| FCHK。ただし元の Gaussian CHK は残っている | `formchk` で書き出すか、COV からインストール済みの変換プログラムを呼び出します。 |
| レポートの項目や軌道行列。ただし必要なデータは `.47` に残っている | 出力オプションを追加して GenNBO を再実行し、その実行のレポートと行列を一緒に使います。通常、新しい SCF 計算は必要ありません。 |
| Fock データなど、アーカイブに含まれていないデータ | ソフトウェアが対応していれば、元の計算状態から書き出します。GenNBO は入力に含まれないデータを補うことはできません。 |
| `.covnbopkg` のファイル一覧 | フォルダーを開くか、ファイルを直接選択します。 |
| 異なる計算のファイルが混在している | 対応する波動関数と NBO 出力を探します。ファイル名を変更しても、内容は変わりません。 |
| 座標だけが残っている | 波動関数を得るには、新しい電子状態計算が必要です。 |

SALC は、読み込んだ軌道と分子の対称性から COV 内で構成します。追加の SCF 計算は必要ありません。形状とエネルギーで必要なデータは異なります。詳しくは、[NBO の結果を使う](AOMO_NBO.ja.md)をご覧ください。

行列出力と `.47` の再解析については、[NBO 7 マニュアル](https://nbo.chem.wisc.edu/nboman.pdf)の B.2.4–B.2.6 節と B.7 節に記載されています。
