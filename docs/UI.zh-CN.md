# 使用 Chemical Orbital Visualiser

[English](UI.md) · **简体中文** · [日本語](UI.ja.md) · [Français](UI.fr.md)

本文对应 COV v0.4.0。已发布安装包的打开方式见[下载说明](../README.zh-CN.md#下载)。

COV 将轨道能量、电子占据和轨道之间的联系放在一起显示。打开已有的 Gaussian FCHK/FCH 或 Molden 文件后，可以从轨道列表中选择轨道，在能级图中比较能量，并导出图像或数据表。分子和所选轨道也可以在三维视图中查看。

## 打开计算文件

使用“打开文件”，将文件拖入窗口，或输入路径。COV 读取计算结果，不运行 Gaussian。FCHK/FCH 和兼容的 Molden 文件可直接打开。已安装 Gaussian 的 `formchk` 时，也可直接打开 CHK。

如果 COV 找不到 `formchk`，将环境变量 `COV_FORMCHK` 设为转换器的完整路径，然后重新启动 COV。也可以先用 `formchk` 生成 FCHK，再打开它。

COV 可以打开计算目录，一并加载波函数和 NBO 文件；目录中有多个计算时，选择要查看的一个。每个输入最多包含 100 个原子。

## 浏览轨道与能量

使用搜索、HOMO/LUMO 跳转和内层、价层、虚轨道筛选。“全部”恢复完整的导入列表；筛选不会从计算中删除轨道。所选轨道的详情包含能量、占据、自旋，以及可用的对称性和轨道名称。

能量单位可以切换为 Ha、eV、J/mol、kJ/mol、cal/mol 或 kcal/mol。原始能量保留为 Hartree，切换显示单位不会改变计算数据。

COV 在有对称性和同类轨道顺序时显示 `2a₁` 等名称；否则显示原 MO 编号和自旋。名称和原编号都可以搜索。接近的能级可以按平均能量分组显示，详情保留各成员自己的能量和身份。分组容差初始为 `1e-5 Ha`，可调整。

## 查看能级图

中心图显示已占据价轨道和附近的虚轨道，以及电子占据情况。可以隐藏较深的内层和较远的虚轨道，使图更易读；这些轨道仍保留在导入列表中。选择轨道进行三维查看不会改变简要能级图的成员或顺序。

COV 可使用线性或非线性能量轴。非线性视图拉开拥挤能级，轴上标明“非线性能量轴”，刻度注明能量值和单位。分组能级使用成员的平均能量。

“导出图片”保存 PNG 和 SVG 图片。在“分析数据（高级）”中点击“导出分析数据”，可单独保存 JSON 和 CSV 数据。图片使用显示中的轨道名和当前界面语言；数据包含轨道编号、能量、占据、自旋、分组和图中显示的成员。

## 查看分子与轨道

旋转、缩放分子，调整原子、键、分子和轨道的显示。默认“增强球棍模型”突出分子骨架；“棍 + 离域虚线”减少原子的遮挡。氢原子的可见性可以单独切换。轨道正、负相位使用不同颜色，等值面阈值可调整。

部分键和接触的显示方式取决于计算中可用的信息。线条和颜色用于辅助阅读，本身不代表测得的键级。

详情窗口可以移动、缩放和重新打开。界面支持中文、英文、日文和法文。

AO–MO 与 NBO 的文件准备和操作见[使用 NBO 结果](AOMO_NBO.zh-CN.md)。现有下载包的启动位置见[仓库首页](../README.zh-CN.md)。
