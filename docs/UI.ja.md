# Chemical Orbital Visualiser の使い方

[English](UI.md) · [简体中文](UI.zh-CN.md) · **日本語** · [Français](UI.fr.md)

このガイドは COV v0.4.0 に対応します。配布パッケージの起動方法は[ダウンロードの説明](../README.ja.md#ダウンロード)にあります。

Chemical Orbital Visualiser（COV）は、軌道のエネルギー、占有数、軌道間の関係を一つの画面に表示します。Gaussian の FCHK/FCH または Molden ファイルを開き、軌道一覧から選択し、エネルギー準位図で比較し、図やデータを書き出せます。分子と選択した軌道の形状は 3D でも確認できます。

## 計算ファイルを開く

ファイルを開く操作、ウィンドウへのドラッグ、またはパス入力で読み込めます。COV は計算結果を読み込みます。Gaussian の計算は実行しません。Gaussian の CHK ファイルは、`formchk` がインストールされていれば変換して開けます。

`formchk` が見つからない場合は、環境変数 `COV_FORMCHK` に変換プログラムの実行ファイルの完全なパスを設定し、COV を再起動します。先に `formchk` で FCHK を作成し、そのファイルを開く方法もあります。

計算フォルダーを開くと、波動関数と NBO ファイルをまとめて読み込めます。複数の計算を含むフォルダーでは、開く計算を選びます。入力ファイルは最大 100 原子です。

## 軌道とエネルギーを調べる

軌道一覧の検索、HOMO/LUMO への移動、内殻・価電子・空軌道の絞り込みを利用できます。「すべて」では読み込んだ軌道の全一覧に戻ります。絞り込みで計算データが削除されることはありません。選択した軌道の詳細には、エネルギー、占有数、スピン、利用可能な対称性や軌道名が表示されます。

エネルギーの単位は Ha、eV、J/mol、kJ/mol、cal/mol、kcal/mol に切り替えられます。元のエネルギーは Hartree で保持され、表示単位を変えても計算値は変わりません。

対称性と同種軌道の順序が分かる場合は、`2a₁` などの軌道名を表示します。それ以外では、元の MO 番号とスピンを表示します。名前と元の番号の両方で検索できます。近いエネルギーの準位を平均エネルギーでまとめて表示することもできます。各軌道のエネルギーと識別情報は詳細に保持されます。グループ化の許容差は初期値 `1e-5 Ha` から変更できます。

## エネルギー準位図を読む

中央の準位図は、占有価電子準位とその近くの空軌道、電子占有数を表示します。深い内殻準位や離れた空軌道を非表示にしても、読み込んだ軌道一覧には残ります。3D 表示のために軌道を選択しても、簡略化された準位図の構成や順序は変わりません。

エネルギー軸は線形または非線形にできます。非線形表示では混み合った準位を離して配置し、軸を非線形エネルギー軸として示します。目盛りにはエネルギーの値と単位が表示されます。まとめた準位は構成軌道の平均エネルギーを使います。

**画像を書き出す** で PNG と SVG の図を保存します。**解析データ（詳細）→ 解析データを書き出す** では、JSON と CSV のデータを別途保存します。図は表示中の軌道名と現在の画面言語を使います。データには軌道番号、エネルギー、占有数、スピン、グループ化、図に表示した準位が含まれます。

## 分子と軌道を見る

表示を回転し、原子、結合、分子、軌道の表示を調整できます。既定の **強調ボール＆スティック** は分子骨格を示します。**結合 + 非局在化破線** では、原子の表示を抑えて骨格を見やすくできます。水素の表示は個別に切り替えられます。軌道表面の正と負の位相は異なる色で表示します。

結合や接触の表示方法には、計算に含まれる情報によって変わるものがあります。線や色だけで結合次数が測定されたことを示すものではありません。

詳細ウィンドウは移動、サイズ変更、再表示ができます。画面は英語、簡体字中国語、日本語、フランス語に対応しています。

AO–MO と NBO の表示については、[NBO の結果を使う](AOMO_NBO.ja.md)を参照してください。
