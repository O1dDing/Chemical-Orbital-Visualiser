## Using and modifying COV

Commercial use, modification and redistribution are allowed under CPAL. Changes to files containing Covered Code, and new files containing Covered Code, fall within its file-level source obligations. When you distribute executables, provide the corresponding Covered Code source and your modifications under CPAL, include the licence and required notices, document your changes and dates, and explain where to obtain that source. Follow section 3.2's source-availability periods. External deployment, including access over a network by others, also triggers source availability under section 15.

Independent code in a Larger Work may keep its own licence and remain closed, provided the CPAL requirements for Covered Code are met. Private use does not by itself require public posting; the distribution and external-deployment rules still apply when their conditions are met.

For a graphical interface, section 14 and Exhibit B require a prominent display at launch or session start, including in Larger Works. The attribution is:

> COV by O1dDing
>
> https://github.com/O1dDing/Chemical-Orbital-Visualiser

COV uses a readable corner area. Keep the attribution visible long enough to read and no less prominent than comparable third-party attribution. Tiny or hidden text does not provide that notice. The standard licence permits other compliant display forms; it does not prescribe a particular corner. There is no GUI display duty when access creates no GUI. Preserve the full Exhibit A source notice as required by section 3.5.

## Citation suggestions — nonbinding

These suggestions add no licence conditions. For a paper or report, one citation in the main text or references is sufficient. Use [CITATION.cff](../CITATION.cff), and record the version or commit you actually used. For example:

> O1dDing. Chemical Orbital Visualiser (COV). https://github.com/O1dDing/Chemical-Orbital-Visualiser. Version or commit used; access date.

For an image shared on its own, you may credit COV in a readable corner or in standard file metadata without a visible mark. This is optional guidance, separate from the software GUI attribution required by CPAL. Metadata should identify COV as the software and O1dDing as its developer, not as the image's copyright holder.
