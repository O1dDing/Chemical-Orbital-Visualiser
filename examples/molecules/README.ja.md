# COV 分子サンプル

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語** · [Français](README.fr.md)

34 種類の分子・イオンについて、配座や基底関数系の異なる 47 件の計算ファイルを収録しています。水、メタン、ベンゼン、簡単な錯体、ねじれ形フェロセンなどがあります。

**[全サンプルをダウンロード](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/samples-2026-10-25/cov-molecule-samples-2026-10-25.zip)**

サンプルは個別または一括でダウンロードできます。ZIP を展開してから COV で開けます。

COV で `open.covnbopkg` を開くと、分子軌道と NBO データをまとめて読み込めます。FCHK ファイル単独でも分子軌道を表示できます。

ここにあるのは計算ファイルです。[COV v0.4.0-pre.4](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.4.0-pre.4) は Windows・macOS・Linux でこれらを開けます。保存済みの結果を見る際、Gaussian や NBO のインストールは不要です。
