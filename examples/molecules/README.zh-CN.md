# COV 分子样本

[English](README.md) · **简体中文** · [日本語](README.ja.md) · [Français](README.fr.md)

34 种分子和离子，共 47 份计算文件，包含不同构象和基组。这里有水、甲烷、苯、简单配合物，以及交错式二茂铁。

**[下载全部样本](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/samples-2026-10-25/cov-molecule-samples-2026-10-25.zip)**

可以下载单个样本，也可以下载整套。解压后即可在 COV 中打开。

在 COV 中打开 `open.covnbopkg`，可一起载入该样本的分子轨道和 NBO 数据。也可以单独打开 FCHK 文件查看分子轨道。

这里提供计算文件。[COV v0.4.0](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.4.0) 可在 Windows、macOS 和 Linux 上打开这些样本；查看已有结果无需安装 Gaussian 或 NBO。
