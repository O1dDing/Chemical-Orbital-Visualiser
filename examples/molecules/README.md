# COV molecule samples

**English** · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [Français](README.fr.md)

34 molecules and ions, with 47 calculations covering different conformations and basis sets. Includes water, methane, benzene, simple complexes and staggered ferrocene.

**[Download all samples](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/samples-2026-10-25/cov-molecule-samples-2026-10-25.zip)**

Each ZIP contains one calculation, or the complete collection. Extract it before opening a sample.

Open `open.covnbopkg` in COV to load a sample’s molecular orbitals and NBO data together. The FCHK file can also be opened on its own.

These are calculation files. [COV v0.4.0](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.4.0) opens them on Windows, macOS and Linux; Gaussian and NBO are not needed to view the saved results.
