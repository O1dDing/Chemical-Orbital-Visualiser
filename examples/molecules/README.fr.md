# Exemples de molécules pour COV

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · **Français**

34 molécules et ions, avec 47 calculs couvrant différentes conformations et bases. La collection comprend l’eau, le méthane, le benzène, des complexes simples et le ferrocène en conformation décalée.

**[Télécharger tous les exemples](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/download/samples-2026-10-25/cov-molecule-samples-2026-10-25.zip)**

Les exemples se téléchargent individuellement ou en une seule archive. Les fichiers sont à extraire avant ouverture dans COV.

Ouvrir `open.covnbopkg` dans COV charge ensemble les orbitales moléculaires et les données NBO. Le fichier FCHK peut aussi être ouvert seul.

Il s’agit de fichiers de calcul. [COV v0.4.0](https://github.com/O1dDing/Chemical-Orbital-Visualiser/releases/tag/v0.4.0) les ouvre sous Windows, macOS et Linux. Gaussian et NBO ne sont pas nécessaires pour consulter les résultats enregistrés.
