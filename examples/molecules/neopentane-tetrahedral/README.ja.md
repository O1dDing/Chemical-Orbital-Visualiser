COV で `open.covnbopkg` を開くと、分子軌道と NBO データをまとめて読み込めます。FCHK ファイル単独でも分子軌道を表示できます。

| ファイル | 内容 |
| --- | --- |

| `nbo.log` | NBO レポート |
| `nbo.47` | NBO アーカイブ |
| `FILE.*` | 軌道行列 |
| `open.covnbopkg` | COV 読み込みリスト |
